# OPS日調アプリ

ドットジェイピー OPS の業務用アプリです。インターン生との面談日程調整、イベントの出欠、スタッフ間の依頼のやり取りを1か所でまとめて扱います。

## ▶ アプリを開く

### https://dot-jp-opsteam.github.io/NitteiChoseiApp/

上のリンクから入れます。ブックマークするならこのURLにしてください。
アプリの置き場所が変わっても、このURLは変わりません。

> **初回は開くまで20〜60秒かかることがあります。**
> しばらく誰も使っていないとサーバーが休止するためです。画面が白いままでも、そのままお待ちください。

うまく開けないときは、直接こちらからも入れます → https://ops-nittyou-app.onrender.com/

## できること

- **面談の日程調整** … インターン生が希望日時を出し、スタッフが確定する。Googleカレンダー連携あり
- **イベントの出欠** … 支部ごとのイベントに出欠を登録する
- **依頼** … スタッフ間で依頼を送り、誰が確認したかを追える
- **メール送信と履歴** … アプリからメールを送り、やり取りを残す
- **アカウント管理** … 支部単位での権限分け（管理者／支部管理者／スタッフ／インターン生）

## 開発者向け

```bash
cd server
npm install
npm start          # http://localhost:8080
```

サーバーを変更したら、必ずテストを流してください。

```bash
node tools/e2e.mjs   # 実際にサーバーを起動して検証します
```

本番データを触る作業の前には、退避を取ってください。手順は
`_specs/2026-08-02-負荷対策と保存基盤の再設計-design.md` の §10 にあります。
