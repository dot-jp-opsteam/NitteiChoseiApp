# 出欠確認候補の直接時刻入力 設計

## 目的

ダークモードで見えにくい候補日付のカレンダーアイコンを白くし、出欠依頼の候補時刻を数字の連続入力だけで設定できるようにする。

## 対象

- スタッフが出欠依頼を作成・編集する画面の候補日時入力。
- 「時間を設定する」がONである候補のみ。

## 日付アイコン

- ダークモードで日付入力のネイティブカレンダーアイコンを白色に表示する。
- ライトモードの既存表示は変更しない。

## 時刻の直接入力

- 開始・終了時刻は数字入力用の欄にする。モバイルでは数字キーボードを優先表示する。
- 開始欄で数字を4桁入力すると、`HH:MM` 形式へ整形する。例：`1146` → `11:46`。
- 開始欄の4桁が有効な時刻に整形できたら、終了欄へ自動的にフォーカスを移す。
- 終了欄は、4桁なら同様に `HH:MM` として扱う。3桁なら先頭へ `0` を補って整形する。例：`457` → `04:57`。
- 入力中は数字以外を除外する。削除・貼り付け・既存時刻の編集も可能にする。
- `00:00`〜`23:59` 以外は不正として明示し、送信できないようにする。
- 終了時刻は開始時刻より後でなければならない。日またぎの時間帯は今回の対象外とする。

## 互換性

- 送信時は既存の `HH:MM` 形式で `start_time` / `end_time` を送るため、API・保存形式・確定処理は変更しない。
- 日付のみ・時間のみ・候補追加の既存挙動は維持する。

## テスト

- ダークモード用のカレンダーアイコン装飾が存在すること。
- `1146` が `11:46` へ正規化され、開始欄から終了欄へ移動すること。
- `457` が `04:57` へ正規化されること。
- 範囲外時刻と終了時刻が開始以前の場合に送信できないこと。
- 既存の `HH:MM` を送信する出欠候補APIテストが通ること。
