# カレンダー表示の整理とライトモードの操作性改善

## 目的

カレンダー画面から利用頻度の低い切替機能を取り除き、主要な操作を分かりやすくする。
あわせて、ライトモードのスタッフホームにある六角形メニューへ薄い差し色を付け、白一色の寂しい印象を改善する。

## 対象

- `index.html`
  - カレンダーの表示状態と操作列
  - 自分のGoogleカレンダーの表示処理
  - スタッフ／支部管理者ホームの六角形メニュー
- `style.css`
  - カレンダー操作ボタン
  - 廃止するリスト表示のスタイル
  - ライトモードのスタッフ用六角形の中面
- `tools/e2e.mjs`
  - 画面構造の回帰確認

## 変更内容

### 1. 自分のGoogleカレンダーは常時表示にする

自分のGoogleカレンダーの予定を取得し、月カレンダーと日別予定へ表示する既存機能は残す。
削除するのは表示／非表示の切替機能だけとする。

削除対象：

- `MYCAL_HIDE_KEY`
- `myCalHidden()`
- `toggleMyCal()`
- カレンダー操作列の人物アイコンボタン
- `myCalItemsFor()` 内の非表示判定

既存端末の `localStorage` に古いキーが残っていても参照されないため、移行処理は追加しない。

### 2. カレンダーを月表示に一本化する

「月／リスト」の切替を削除し、常に月表示を描画する。

削除対象：

- `calMode`
- `setCalMode()`
- `agendaView()`
- `.calview-tabs`
- `.agenda` とその子要素の専用CSS

月表示の生成処理は条件分岐の外へ出す。日付選択、月送り、全画面表示、予定追加は変更しない。

### 3. 全社カレンダーを明確なボタンにする

Googleカレンダー側の全社カレンダーを開くボタンへ専用クラス `.sharedcal-link` を付ける。

- 背景：`var(--brand-soft)`
- 枠：`var(--brand)`
- 文字：`var(--brand-d)`
- 太さ：800
- ホバー／キーボードフォーカス：背景を少し濃くし、上へ2px移動
- アクティブ：移動を戻して押下感を出す

全社予定を自分の画面から隠す目アイコンは既存機能として残す。

### 4. スタッフホームの六角形に薄い差し色を付ける

スタッフと支部管理者の六角形グリッドだけを `.staff-hexes` で囲む。
ライトモード時に限り、各六角形の中面 `::before` を `var(--a-soft)` で塗る。

これにより、既存の `a1`〜`a4` の差し色に合わせて、緑・橙・青・ピンクの薄い中面になる。

変更しない範囲：

- ダークモード
- インターン生ホーム
- 全体管理者ホーム
- 六角形の輪郭、文字、アイコン、バッジの既存配色

## UI構造

カレンダー上部の操作列は次の順序にする。

1. 全社カレンダーをGoogleで開くボタン（設定済みの場合）
2. 全社予定の表示／非表示ボタン（設定済みの場合）

自分の予定ボタンと月／リスト切替がなくなるため、操作列は短くなる。
全画面表示でも同じ操作列を使う。

## データとエラー処理

- `/api/my-calendar/events` と `/api/shared-calendar/events` は変更しない。
- Googleカレンダーの取得失敗時の既存挙動は変更しない。
- 非表示状態の保存処理を削除しても、サーバー保存データには影響しない。
- 全社予定の非表示設定は今回の対象外として保持する。

## テスト

実装前に、次の条件を検査する回帰テストを追加して失敗を確認する。

1. カレンダー画面に「リスト」切替を生成しない。
2. 自分のGoogle予定の表示／非表示ボタンを生成しない。
3. 自分のGoogle予定は古い非表示キーにかかわらず一覧へ含まれる。
4. 全社カレンダーボタンに `.sharedcal-link` が付く。
5. スタッフ／支部管理者の六角形だけが `.staff-hexes` 配下にある。

実装後は以下を確認する。

- 追加した回帰テスト
- `node tools/test-fmt.mjs`
- `node tools/e2e.mjs`
- `git diff --check`

## 対象外

- Googleカレンダー連携自体の削除
- 全社予定の表示／非表示機能の削除
- カレンダーAPIやデータベースの変更
- インターン生／全体管理者ホームの六角形配色変更
