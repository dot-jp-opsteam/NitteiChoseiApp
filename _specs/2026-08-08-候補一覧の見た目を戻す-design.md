# 候補一覧の見た目を戻す

出欠確認をつくるときの「選んだ日程の一覧」を、丸いピル型の横並びから
**角丸の四角い枠の縦並び**へ戻す。

対象は `index.html` の `reqOptionsHTML` と `style.css` の該当ブロックだけ。
`REQFORM.opts` の持ち方もサーバーも変えない。

## なぜ変えるか

`38db304` で選んだ日をチップにして横に並べた。狙いは「日を5件6件選んでも画面が
埋まらないこと」だったが、丸いピルが折り返して並ぶ見た目が候補の一覧として読みにくい。
縦に1件ずつ積むほうが、どの日を何時からにしたのかを目で追える。

縦に長くなる点はユーザーが承知のうえで選んだ（シート内はスクロールできるので実害なし）。

## 変えるもの

### 1. 並び方

`.optlist` の `flex-wrap:wrap` をやめ、`flex-direction:column` にする。

### 2. 1行の見た目

クラス名を `.optchip` から **`.optrow`** に戻す。中身が「チップ」ではなく「行」に
戻るため。旧 `.optrow` のCSSは `38db304` で消えているので衝突しない。

| | 前 | 後 |
|---|---|---|
| 角 | `border-radius:999px` | `12px` |
| 背景 | `var(--brand-soft)` | なし（パネル色のまま） |
| 枠 | `var(--hint-line)` | `var(--line)` |
| `⎘` `×` の角 | `999px` | `8px` |

日付ラベルは `min-width:7.2em` で幅を揃える。「8月1日(金)」と「8月12日(火)」で
長さが違うため、揃えないと行ごとに時刻の位置がずれる。

### 3. 中身は変えない

日付は文字表示のまま、時刻は `input type="time"` のまま、`⎘`（同じ日をふやす）と
`×` もそのまま。ミニカレンダーは触らない。

### 4. スマホ幅

日付＋時刻2つ＋ボタン2つは 375px の1行に収まらない（合計 約380px に対して
使える幅は約343px）。`@media(max-width:520px)` で日付を上の行に出して折り返す。
枠の角丸は 12px のまま（チップのときは 999px から落とす必要があったが、
はじめから 12px なので分岐が要らなくなる）。

## 触るファイル

| ファイル | 変更 |
|---|---|
| `index.html` | `reqOptionsHTML` の `optchip` → `optrow`、コメントの書き直し |
| `style.css` | `.optlist` / `.optrow` / `.optcopy` / `.optx` と狭い画面の分岐 |
| `tools/e2e.mjs` | 「タブで横に並べる」の検査を「縦1列で並べる」に書き換え |
| `server/` | 変更なし |

`tools/e2e.mjs` の該当項目は消さずに、新しい仕様の確認へ書き換える。

## 確かめかた

1. `node tools/test-fmt.mjs` と `node tools/e2e.mjs` を通す
2. ブラウザで実際に触る
3. 見るもの: 候補が縦に1件ずつ積まれるか、角丸の四角い枠になっているか、
   日付の長短で時刻がずれないか、ダークモードで枠が沈まないか、375px幅で折り返すか

## やらないこと

- ミニカレンダーの変更
- 時刻入力の作り直し（OS標準の `input type="time"` のまま）
- 出欠を答える側の画面（`attendance.html`、公開ページ）の変更
